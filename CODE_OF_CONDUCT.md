# Code of Conduct

## Our pledge

This project adopts the **Contributor Covenant, version 2.1** as its
code of conduct. We pledge to make participation in our community a
welcoming, respectful experience for everyone.

The full text of the Contributor Covenant 2.1 is published at:

  https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project (filing issues, opening pull requests,
discussing in any project channel) you agree to abide by its terms.

## Scope

This Code of Conduct applies within all project spaces, and also when
an individual is officially representing the project in public spaces.

## Reporting

If you observe behaviour that you believe is inconsistent with the
Contributor Covenant, please report it privately to the maintainer:

  - GitHub: open a private security advisory on the repository
    ("Security" tab → "Report a vulnerability"); the same channel is
    used for sensitive conduct reports so the conversation stays
    private.
  - Email: `mayankbhaskar007@gmail.com`

All reports will be reviewed and investigated promptly and fairly. The
maintainer is obligated to respect the privacy and security of the
reporter of any incident.

## Enforcement

The maintainer is responsible for clarifying and enforcing the
Contributor Covenant. Consequences may include private warnings,
temporary bans from project communication channels, or permanent bans
from the project, depending on severity. The full enforcement guidelines
that this project follows are published on the Contributor Covenant
website at the URL above.
